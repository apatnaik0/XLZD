# Additional CNP Experiment Notebooks

This folder holds the older fixed-path CNP notebooks that correspond to specific training modes:

- `cnp_xlzd_minibatch_workflow.ipynb`
- `cnp_xlzd_fixedcontext_workflow.ipynb`
- `cnp_xlzd_fullpass_workflow.ipynb`

These notebooks are kept for reference and reproducibility.

The main entry point for running CNP experiments should now be:

- [`../cnp_xlzd_workflow.ipynb`](../cnp_xlzd_workflow.ipynb)

That notebook can switch between:

- `default`
- `minibatch`
- `fixedcontext`
- `fullpass`

Use the notebooks in this folder only if you specifically want the historical fixed-path versions.
